# 会话恢复失败重试

实现：`fa5c6e4`。

远端恢复失败以会话为单位保留错误，提供重试按钮。恢复成功前禁用发送、追加和队列继续操作，暂停该会话队列；文本仍可编辑，其他会话不受影响。成功后采用服务端工作区继续发送。失败不会自动重发消息。

验收通过：

- `thread-restore-retry-ui.cjs`：失败后按钮/Enter 无发送，草稿可编辑且跨会话隔离；延迟重试禁止重复操作，成功后使用确认的 cwd；离开会话后的迟到失败不污染当前会话。
- `turn-queue-ui.cjs`、`queue-inflight-ui.cjs`：FIFO、取消、失败暂停、存储失败和防重放回归。
- `related-threads-ui.cjs`：关联导航和草稿回归。
- 生产构建通过，保留既有包体积警告。

提交后修正：退出恢复 effect 时清理所属恢复标记，避免切换到本机会话后留下全局服务忙碌状态。扩展恢复测试及构建通过。测试模拟 app-server；不覆盖全部真实网络故障或服务器状态组合。
