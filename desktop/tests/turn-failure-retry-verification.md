# 失败回合恢复验收（2026-09-18）

核心不变量：失败消息的 `error-{turnId}` 与原始用户消息的 `turnId` 是唯一关联键；恢复动作从该键读取原始文本、附件、技能和插件，恢复到当前 Composer，不复制历史用户消息、不自动发起新回合，也不删除错误记录。已有草稿或运行中的回合时，恢复按钮保持禁用，避免覆盖用户输入或并发发送。

已通过：

- `turn-failure-retry-ui.cjs`：失败线程恢复文本、附件、技能和插件，Composer 可编辑，错误记录保留，状态与历史一致，不自动发送。
- `turn-lifecycle-ui.cjs`：并发线程、追加指令拒绝、停止拒绝、晚到失败、提前完成、断线恢复回归通过。
- TypeScript 编译和 Vite 生产构建通过。

恢复按钮的实际行为是“恢复本轮输入”，用户检查或修改草稿后再点击发送；这保留了 Codex 类工作流中的人工确认边界。
